# Issue #20 作業ログ: 求人一覧をカンバン表示へ切り替えられるようにする

## 実装のポイント

- **データ取得は一覧画面と同じ`fetchJobs()`を使い回している。** カンバン専用のAPIエンドポイントは作らず、取得した配列をクライアント側で`JOB_STATUSES`の順に`filter()`してステータスごとの列に振り分けているだけ。これにより「一覧とカンバンでデータがズレる」という状態がそもそも構造的に起こりにくい(#24のテストで実際に確認する予定)
- 列のヘッダーには件数バッジを表示。0件の列は「なし」とグレーで表示
- 9列は横幅が広くなるため、`.kanban-board`に`overflow-x: auto`を設定し、ページ全体ではなくカンバン部分だけが横スクロールする(既存の一覧テーブルの`.table-scroll`と同じパターン)
- カードは会社名・職種・応募日・給与のみを表示するシンプルな構成。ステータスは列そのものが表しているためカード内には表示していない

## 動作確認方法

### 型チェック

```bash
cd frontend
npx tsc --noEmit -p tsconfig.app.json
```

### ブラウザでの確認手順

1. 一覧画面(`/`)の「カンバン表示」リンクから`/kanban`に遷移
2. 9列(未応募〜辞退)が表示され、各求人が正しいステータスの列に入っていることを確認
3. 「一覧表示」リンクで`/`に戻れることを確認
4. 開発者ツールで各列の`border-top-color`が、一覧画面の行アクセントカラー・ステータスバッジと同じ色になっていることを確認

### 確認結果

すべて想定通り。実際にブラウザで確認した内容:

- `応募済`のTEST株式会社、`内定`のテスト株式会社がそれぞれ正しい列に表示された
- 他の7列(データなし)は「なし」と表示
- 各列の上部ボーダー色をJavaScriptで取得し、`tone-info`(応募済)→青、`tone-profit`(内定)→緑など、`getStatusTone()`のマッピング通りであることを確認
- コンソールエラーなし
