# 求人管理Webアプリ MVP要件定義

## 目的

自分の転職活動における応募求人を一元管理し、選考状況の把握漏れ・対応漏れを防ぐ。

## ユーザー

本人のみ(個人用ツール)。認証機能は不要、もしくは最小限の簡易ログインのみ。

## 開発規模

一人開発、1〜2週間程度で完成させるMVP。

---

## 必要機能(第一段階)

| 機能           | 内容                                               |
| -------------- | -------------------------------------------------- |
| 求人登録       | 会社名・職種などを入力して新規登録                 |
| 一覧表示       | 登録済み求人をリスト表示、ステータスで見分けられる |
| ステータス変更 | 選考状況を更新                                     |
| メモ           | 自由記述でメモを残せる                             |

※検索・並び替え・応募期限リマインドなどは次段階以降の拡張候補とする。

---

## データ項目

| 項目              | 必須 | 型/備考                                                 |
| ----------------- | ---- | ------------------------------------------------------- |
| 会社名            | ○    | 文字列                                                  |
| 職種/ポジション名 | ○    | 文字列                                                  |
| ステータス        | ○    | 下記9段階の選択式                                       |
| 応募日            | -    | 日付                                                    |
| 求人URL           | -    | 元の求人ページへのリンク                                |
| 勤務地            | -    | 文字列                                                  |
| 給与/年収レンジ   | ○    | 例:「500〜650万円」などの文字列 or 上限/下限の数値2項目 |
| メモ              | -    | 自由記述、選考メモや所感                                |
| 登録日時/更新日時 | 自動 | システム管理(created_at / updated_at)                   |

### ステータス選択肢(9段階)

1. 未応募
2. 応募済
3. 書類選考中
4. 一次面接
5. 二次面接
6. 最終面接
7. 内定
8. 不採用
9. 辞退

---

## 画面一覧(2画面構成)

### 1. 求人一覧画面

- 登録済み求人をカード or テーブルで表示
- ステータスごとに色分け表示
- 各求人から「求人フォーム画面(編集モード)」へ遷移
- 「新規登録」ボタンから「求人フォーム画面(新規登録モード)」へ遷移

### 2. 求人フォーム画面(新規登録/編集 兼用)

- 新規登録時:空フォームで表示、保存で一覧へ戻る
- 編集時:既存データが入った状態で表示、保存で一覧へ戻る
- ステータス変更・メモ編集もこの画面で行う
- 削除機能もここに配置(任意)

---

## 次段階以降の拡張候補(MVP後)

- 検索・フィルタ・並び替え
- 応募期限や面接日のリマインド通知
- ステータス変更履歴の記録
- ダッシュボード(応募社数・内定率などの集計)
